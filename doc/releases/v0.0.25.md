## Abstract

YaGo v0.0.25 repairs the ingest content-quality gate, which was discarding ordinary pages as repetition spam. Its two Gopher repetition measures counted the same characters once per overlapping n-gram occurrence, so the value was not a fraction at all: a Wikipedia article measured 0.323 and a VirtualBox manual page 0.716 against a 0.15 limit. Both now measure 0.054 and 0.095 and are stored. On the reference deployment this rejected 10,277 pages in one day, so the local index could not grow and every repeated query fell back to the web. Korean pages no longer bypass the gate entirely, and a page discussing lorem ipsum is no longer treated as filler. Thresholds are unchanged.

## Changes

### Repetition filters measure a real share of the text

- `duplicatedNGramCharacterShare` summed `occurrences x characters` for every duplicated n-gram over a window sliding by one word. A character inside overlapping duplicates was therefore counted up to n times per occurrence, and the result had a ceiling near n rather than 1. It is now the fraction of characters that are redundant — inside a repeat of an n-gram already seen earlier in the text — with each character counted once, matching the FineWeb reference implementation of Gopher Table A1. The first occurrence of a phrase is the page saying something; only its repeats are duplication.
- `topNGramCharacterShare` had the same multiplication and additionally selected the gram maximising occurrences times length rather than the most frequent one, so a page with no repetition at all could be rejected. It now marks the words its occurrences cover, counts each character once, and reports zero when no n-gram repeats.
- Measured on the pages the reference deployment actually refused: the Wikipedia article `Hinduism in Singapore` fell from 0.323 to 0.054 and the VirtualBox `Security.html` manual from 0.716 to 0.095, against a 0.15 limit; both are now stored. Repetition spam is still refused — a single phrase repeated 200 times measures 0.4615 and a templated doorway page 0.2257 against a 0.20 limit.
- The configured Gopher limits are unchanged. This release corrects the computation, not the calibration.

### Korean pages face the gate

- Hangul was listed among the scripts written without word separators, whose token statistics are meaningless and which therefore skip every rule. Korean separates words with spaces, so every Korean page — keyword spam included — bypassed the whole gate. Hangul is no longer listed; Han, Hiragana, Katakana, Thai, Lao, Khmer and Myanmar still skip it.

### Placeholder text

- The filler rule matched the phrase `lorem ipsum` anywhere in the lowercased page, so a typography guide, CSS documentation, a generator, or the encyclopedia entry about the placeholder was discarded. It now requires an unbroken run of placeholder words.

## Compatibility

- No environment variable, Admin setting, route, request field, response field, public schema, listener, port, service, image name, package path, Bleve mapping, document encoding, or deployment topology changes. No dependency changes. No contract or wire-format change.
- The gate becomes more permissive for ordinary prose and stricter for Korean pages, which previously skipped it. Operators who disabled `YAGO_INGEST_QUALITY_GATE` to work around the defect can enable it again.
- Documents already stored are untouched. Pages previously refused were never stored and were not scheduled for recrawl, so they are not retried automatically; their hosts must be seeded again for the corrected gate to see them.

## Upgrade and rollback

1. After the immutable tag workflow succeeds, download the architecture-matching v0.0.25 Debian package. Verify its GitHub artifact attestation against repository `D4rk4/yago`, workflow `.github/workflows/release.yml`, tag ref `refs/tags/v0.0.25`, and the tagged source commit before stopping either service.
2. Follow the target's data-protection policy. Generic bare-metal nodes take one coordinated stopped backup. The documented `root@yagoseek.dev` exception preserves every existing archive under `/opt/yago/backups` and creates no new pre-upgrade backup; stage the verified package under `/opt/yago/releases`.
3. Stop `yago-crawler` and then `yago-node`. Install the package with `dpkg -i` and confirm that package installation did not start either service automatically.
4. Start `yago-node` first, then `yago-crawler` after node readiness. Verify both versions, `/health`, `/ready`, and the configured listeners.
5. Watch `crawl_ingest_low_quality_total` against `crawl_search_index_documents_total`. The refusal rate should fall sharply and the document count should start rising; the crawler's `crawl page rejected by node content-quality gate` lines name any remaining rule.
6. Keep production verification observation-only.

For rollback, stop crawler and node, reinstall the v0.0.24 package, start and verify the node, and then start the crawler. No index rebuild or data restore is required. The older node resumes discarding ordinary pages as repetition spam and resumes letting Korean pages skip the gate; documents stored while v0.0.25 ran remain valid and searchable.

## Known limitations

- Pages refused before this release are not retried. They were never stored and never scheduled for recrawl, so their hosts must be seeded again.
- `no-function-words` still over-rejects prose in languages the stopword dictionary does not cover. Skipping the rule when no dictionary word appears was implemented and reverted: genuine keyword stuffing has no function words either, so the two are indistinguishable without language detection, which this release does not add.
- `non-alphabetic` and `word-length` remain aggressive on table-heavy documents and on languages with short words. Their computations were checked and are correct; only their calibration is arguable, and it is left unchanged rather than adjusted without data.
- The gate refuses a whole ingest batch rather than only the offending document.
- `unsegmentedSkipShare` remains a hard 0.3 boundary, so a page just above the share skips every rule while one just below receives word statistics of limited meaning.
- The placeholder rule keys on the classic Latin filler vocabulary; other filler generators are not recognised.
